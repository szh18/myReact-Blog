## 欢迎

这是博客的第一篇文章。本博客使用 **React 19** + **Vite 7** 构建，所有文章内容由 Markdown 文件驱动。

### 技术栈

- **React 19** — UI 框架
- **Vite 7** — 构建工具
- **React Router v7** — 路由
- **react-markdown** — Markdown 渲染
- **highlight.js** — 代码高亮

### 代码示例

```javascript
function greet(name) {
  return `你好，${name}！欢迎来到我的博客。`;
}

console.log(greet('访客'));
```

### 特性

1. 支持 Markdown 语法
2. 代码语法高亮
3. 分类和标签
4. 全文搜索
5. RSS 订阅
6. Giscus 评论
